# Online Nursery Management System

## Introduction
The Online Nursery Management System is a Java-based application developed using Java Swing, JDBC, and MySQL. It provides an easy platform for customers to register, login, browse plants, and place orders online.

## Features
- User Registration
- User Login
- Plant Catalog
- Shopping Cart
- Order Management
- MySQL Database Integration

## Technologies Used
- Java
- Java Swing
- JDBC
- MySQL
- Eclipse IDE

## System Modules
1. Registration Module
2. Login Module
3. Product Catalog Module
4. Order Management Module
5. Database Module

## Database
- Users Table
- Orders Table
